# TrendPulse Backlog Workspace

Каталог для планирования реализации в формате epics/stories/sprints.

## Содержимое

- `epics-v1.md` — список эпиков и целевые outcomes.
- `stories-sprint-01.md` — user stories и задачи на спринт 1.
- `stories-sprint-02.md` — user stories и задачи на спринт 2.
- `definition-of-done.md` — единые критерии готовности.

## Правила

1. Каждая story должна ссылаться на PRD-раздел.
2. Каждая story должна иметь acceptance criteria (Given/When/Then или эквивалент).
3. Technical tasks включать только если они привязаны к пользовательской ценности или риску.
