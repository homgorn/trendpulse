FAQ

What is TrendPulse?

TrendPulse is an AI-driven platform for game studios to discover market trends and generate game concepts. It helps turn market noise into successful games by analyzing trends across multiple industries.

How does TrendPulse work?

TrendPulse uses multi-provider LLM routing to generate game ideas based on market trends. It combines RAG-based retrieval with AI to create actionable game concepts.

Is TrendPulse free to use?

TrendPulse offers a free tier for development and testing. Production usage requires API keys from supported LLM providers (OpenRouter, Gemini).

What providers does it support?

TrendPulse supports OpenRouter (300+ models), Google Gemini, and can be extended to other providers. Automatic fallback ensures reliability.

How do I integrate with my project?

Use the REST API (POST /v1/generate) or CLI (trendpulse generate). Check the documentation for examples.

What programming languages are supported?

TrendPulse provides REST API (any language) and CLI (Python). Official SDKs coming soon for JavaScript, Go, and Rust.

Can I use my own LLM model?

Yes! TrendPulse supports custom model configuration. Implement the LLMBackend interface to add your own provider.

Does TrendPulse support real-time streaming?

Yes, the stream_chat method is available in all backends for streaming responses.

How does the circuit breaker work?

After 3 consecutive failures (configurable), the circuit opens for 20 seconds (configurable), skipping that provider on subsequent requests.

Is there a rate limit?

Yes, default is 30 requests per 60 seconds. Configurable via RATE_LIMIT_REQUESTS and RATE_LIMIT_WINDOW_SECONDS.
