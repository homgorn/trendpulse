🚀 Getting Started

Set up TrendPulse in 5 minutes

← Back to Docs API Reference →

Prerequisites

  • Python 3.11+ — Required for TrendPulse
  • API Key — At least one LLM provider key (OpenRouter or Gemini)
  • pip — Package manager
Quick Tip: For the best experience, use a virtual environment (venv) to isolate TrendPulse from other Python projects.

Installation

1. Clone the Repository

git clone https://github.com/trendpulse/trendpulse.git
cd trendpulse

2. Create Virtual Environment

# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/macOS
python -m venv .venv
source .venv/bin/activate

3. Install Dependencies

pip install -e ".[dev]"

Configuration

Create .env File

Create a .env file in the project root:

# LLM Providers (at least one required)
OPENROUTER_API_KEY=sk-or-v1-...
GEMINI_API_KEY=your-gemini-key

# Optional Configuration
DEFAULT_PROVIDER=openrouter
FALLBACK_PROVIDER=gemini
LOG_LEVEL=INFO

# Rate Limiting
RATE_LIMIT_REQUESTS=30
RATE_LIMIT_WINDOW_SECONDS=60

# Observability
OTEL_ENABLED=false
OTEL_ENDPOINT=http://localhost:4317
Security Note: Never commit your .env file to version control. Add it to .gitignore if needed.

Running TrendPulse

Start the API Server

uvicorn trendpulse.api:app --host 127.0.0.1 --port 8100 --reload

API will be available at http://127.0.0.1:8100

Verify Installation

# Health check
curl http://127.0.0.1:8100/health

# Ready check
curl http://127.0.0.1:8100/ready

# Metrics
curl http://127.0.0.1:8100/metrics

CLI Usage

Generate a Game Concept

trendpulse generate \
  --theme "ai tools" \
  --platform "tiktok" \
  --region "global" \
  --budget-mode balanced \
  --task-type creative

Quick Examples

Python API Call

import requests

response = requests.post(
    "http://127.0.0.1:8100/v1/generate",
    json={
        "theme": "ai tools",
        "platform": "tiktok",
        "region": "global",
        "budget_mode": "balanced",
        "task_type": "creative"
    }
)
print(response.json())

cURL

curl -X POST http://127.0.0.1:8100/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"theme":"ai tools","platform":"tiktok","region":"global","budget_mode":"balanced","task_type":"creative"}'
