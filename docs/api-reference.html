Base URL

http://127.0.0.1:8100

Endpoints

GET /health

Health check endpoint. Always returns OK status.

Response:

{
  "status": "ok"
}
GET /ready

Readiness check. Verifies LLM provider configuration.

Response:

{
  "status": "ready",
  "provider": "openrouter"
}

// or
{
  "status": "not_ready",
  "reason": "no_providers_configured"
}
GET /metrics

Prometheus metrics endpoint.

Response:

trendpulse_requests_total 1234
trendpulse_requests_success_total 1200
trendpulse_requests_error_total 34
trendpulse_llm_latency_ms_sum 45678.9
...
POST /v1/generate

Generate a game concept based on market trends.

Request Body:

Parameter Type Required Description
theme string Yes Theme or niche (2-500 chars)
platform string Yes Target platform: tiktok, mobile, steam, console
region string No Target region (default: "global")
budget_mode string No "balanced" or "low_cost" (default: "balanced")
task_type string No "creative", "analysis", or "reasoning" (default: "creative")

Example Request:

{
  "theme": "ai tools",
  "platform": "tiktok",
  "region": "global",
  "budget_mode": "balanced",
  "task_type": "creative"
}

Example Response:

{
  "idea": "AI-powered short-form video creator...",
  "audience": "Gen Z content creators...",
  "monetization": "Freemium with premium features...",
  "risks": ["Market saturation", "Platform dependency"],
  "sources": ["TikTok trends", "Product Hunt data"],
  "provider": "openrouter",
  "model": "anthropic/claude-3.5-sonnet",
  "profile": "creative"
}

Error Responses

Status Code Code Description
400 VALIDATION_ERROR Invalid request parameters
400 PROVIDER_ERROR LLM provider returned an error
400 PROVIDER_TIMEOUT LLM request timed out
400 CONFIGURATION_ERROR Invalid configuration
429 RATE_LIMIT_EXCEEDED Too many requests
500 INTERNAL_ERROR Internal server error

Request Headers

Header Required Description
x-trace-id No Custom trace ID for distributed tracing
Content-Type Yes Must be "application/json"

CLI Commands

Generate Command

trendpulse generate \
  --theme "ai tools" \
  --platform "tiktok" \
  --region "global" \
  --budget-mode balanced \
  --task-type creative

Options

Option Short Description
--theme -t Theme or niche for idea generation
--platform -p Target platform
--region -r Target region (default: global)
--budget-mode -b Budget mode: balanced or low_cost
--task-type -T Task type: creative, analysis, reasoning
