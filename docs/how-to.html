Quick Start Guides

1Generate Your First Game Concept

Learn how to generate a game idea in 3 simple steps.

  1. Start the server: uvicorn trendpulse.api:app --reload
  2. Send a request:
curl -X POST http://127.0.0.1:8100/v1/generate \
  -H "Content-Type: application/json" \
  -d '{
    "theme": "space exploration",
    "platform": "mobile",
    "region": "global",
    "budget_mode": "balanced",
    "task_type": "creative"
  }'
  1. Receive your game concept: The API returns a complete idea with audience, monetization, risks, and sources.

2Use Python SDK

Integrate TrendPulse into your Python application.

import requests

def generate_game_concept(theme, platform):
    response = requests.post(
        "http://127.0.0.1:8100/v1/generate",
        json={
            "theme": theme,
            "platform": platform,
            "budget_mode": "balanced",
            "task_type": "creative"
        }
    )
    return response.json()

# Generate 10 game ideas
themes = ["ai tools", "crypto", "fantasy", "horror", "sports"]
for theme in themes:
    result = generate_game_concept(theme, "mobile")
    print(f"{theme}: {result['idea'][:100]}...")

3Batch Generation

Generate multiple game concepts for comparison.

import asyncio
import aiohttp

async def generate_batch(themes):
    async with aiohttp.ClientSession() as session:
        tasks = []
        for theme in themes:
            payload = {
                "theme": theme,
                "platform": "mobile",
                "task_type": "creative"
            }
            tasks.append(session.post(
                "http://127.0.0.1:8100/v1/generate",
                json=payload
            ))
        
        responses = await asyncio.gather(*tasks)
        return [await r.json() for r in responses]

# Generate 5 concepts at once
themes = ["ai tools", "crypto", "fantasy", "horror", "sports"]
results = asyncio.run(generate_batch(themes))

for r in results:
    print(f"Theme: {r.get('idea', 'N/A')[:50]}...")
    print(f"Provider: {r['provider']}\n")

4Use Low-Cost Mode

Reduce API costs by using cheaper models.

# Set budget_mode to "low_cost" to use cheaper models
response = requests.post(
    "http://127.0.0.1:8100/v1/generate",
    json={
        "theme": "ai tools",
        "platform": "mobile",
        "budget_mode": "low_cost",  # Uses Gemini Flash
        "task_type": "creative"
    }
)

Effect: Switches to gemini-2.0-flash for cost optimization.

5Custom Analysis Mode

Get deeper analysis instead of creative ideas.

# Use task_type for different output styles
response = requests.post(
    "http://127.0.0.1:8100/v1/generate",
    json={
        "theme": "mobile gaming trends 2024",
        "platform": "mobile",
        "task_type": "analysis"  # or "reasoning"
    }
)

# Options:
# - creative: Generate new game ideas
# - analysis: Analyze market data
# - reasoning: Deep logical analysis

6Add Custom Headers

Track requests with custom trace IDs.

import uuid

trace_id = str(uuid.uuid4())
headers = {
    "Content-Type": "application/json",
    "x-trace-id": trace_id
}

response = requests.post(
    "http://127.0.0.1:8100/v1/generate",
    json={"theme": "ai", "platform": "mobile"},
    headers=headers
)

print(f"Trace ID: {trace_id}")
print(f"Response: {response.json()}")

7Deploy with Docker

Run TrendPulse in a container.

# Build the image
docker build -t trendpulse:latest .

# Run with environment variables
docker run --rm -p 8100:8100 \
  -e OPENROUTER_API_KEY=sk-or-... \
  -e GEMINI_API_KEY=... \
  trendpulse:latest
