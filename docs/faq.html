General

What is TrendPulse?

TrendPulse is an open-source AI-driven platform for game studios to discover market trends and generate game concepts. It helps turn market noise into successful games by analyzing trends across multiple industries.

Who is TrendPulse for?

TrendPulse is designed for:

  • Indie game developers looking for game ideas
  • Game studios validating concepts before development
  • Game jam participants seeking inspiration
  • Game design students learning market analysis
  • AAA publishers researching market trends
Is TrendPulse free?

TrendPulse itself is open-source and free. However, you'll need API keys from LLM providers (OpenRouter or Gemini) to use the AI features. These providers have their own pricing.

Technical

What programming languages are supported?

TrendPulse provides:

  • Python — Full SDK and CLI support
  • REST API — Any language can call the HTTP endpoints
  • CLI — Command-line interface for scripts
What LLM providers are supported?

Currently supported:

  • OpenRouter — 300+ models, including Claude, GPT, Llama
  • Google Gemini — Gemini Pro, Flash models

You can also implement custom backends by extending the LLMBackend interface.

How does the circuit breaker work?

After 3 consecutive failures (configurable via LLM_CIRCUIT_BREAKER_FAIL_THRESHOLD), the circuit opens for 20 seconds (configurable via LLM_CIRCUIT_BREAKER_OPEN_SECONDS). During this time, requests skip that provider and try the next one.

Is there rate limiting?

Yes, default is 30 requests per 60 seconds. Configure via:

  • RATE_LIMIT_REQUESTS
  • RATE_LIMIT_WINDOW_SECONDS
Does TrendPulse support streaming?

Yes, all backends implement stream_chat() method for streaming responses.

What Python version is required?

Python 3.11 or higher is required.

Pricing & Costs

How much does TrendPulse cost?

TrendPulse is free and open-source. You only pay for the LLM API calls to your provider. OpenRouter and Gemini both have free tiers for development.

How can I reduce LLM costs?

Use budget_mode: "low_cost" to switch to faster, cheaper models like Gemini Flash.

Deployment

How do I deploy TrendPulse?

Multiple deployment options:

  • Docker — docker build && docker run
  • Docker Compose — docker compose up
  • Kubernetes — Apply manifests from k8s/
  • Direct — uvicorn trendpulse.api:app
Can I run TrendPulse on serverless?

Yes, TrendPulse works with any ASGI server and can be deployed to AWS Lambda, Google Cloud Run, or similar platforms.

What are the system requirements?

Minimum:

  • Python 3.11+
  • 512MB RAM
  • 1 CPU core

Recommended for production:

  • Python 3.11+
  • 2GB RAM
  • 2+ CPU cores

Troubleshooting

API returns 429 error

You've exceeded the rate limit. Wait 60 seconds or adjust RATE_LIMIT_REQUESTS in your configuration.

All providers failed error

Check:

  • API keys are valid and not expired
  • Network connectivity to LLM providers
  • Check /ready endpoint for provider status
Invalid JSON response from LLM

The LLM returned malformed JSON. This is usually temporary—retry the request.

Metrics not showing up

Ensure you're calling /metrics endpoint. Metrics are in Prometheus text format.

Contributing

How can I contribute?

We welcome contributions! See the GitHub repository for guidelines.

How do I add a new LLM provider?

Implement the LLMBackend interface in a new file under adapters/ and register it in the gateway.
