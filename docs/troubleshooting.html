Common Errors

400 VALIDATION_ERROR - Invalid request
{"code": "VALIDATION_ERROR", "message": "..."}
Solution: Check request parameters. Ensure:
  • theme: 2-500 characters
  • platform: tiktok, mobile, steam, console
  • budget_mode: balanced or low_cost
  • task_type: creative, analysis, reasoning
400 PROVIDER_ERROR - LLM provider error
{"code": "PROVIDER_ERROR", "message": "OpenRouter error: ..."}
Solution:
  • Check API key is valid
  • Check provider status (OpenRouter status page)
  • Check network connectivity
  • Try fallback provider
400 PROVIDER_TIMEOUT - Request timed out
{"code": "PROVIDER_TIMEOUT", "message": "Provider timeout provider=openrouter"}
Solution:
  • Increase LLM_REQUEST_TIMEOUT_SECONDS
  • Check network latency
  • Try faster model (low_cost mode)
  • Check provider status
429 RATE_LIMIT_EXCEEDED
{"detail": "Rate limit exceeded"}
Solution:
  • Wait 60 seconds (default window)
  • Increase RATE_LIMIT_REQUESTS in config
  • Implement client-side rate limiting
400 CONFIGURATION_ERROR - No providers configured
{"code": "CONFIGURATION_ERROR", "message": "No LLM providers configured"}
Solution:
  • Set OPENROUTER_API_KEY or GEMINI_API_KEY
  • Check .env file is in correct location
  • Restart application after config change
All providers failed
ProviderError: All providers failed: ...
Solution:
  1. Check /ready endpoint for provider status
  2. Verify API keys are valid
  3. Check network connectivity to providers
  4. Check provider status pages
  5. Try with single provider first

Debugging Tips

Enable Debug Logging

LOG_LEVEL=DEBUG

Check Circuit Breaker Status

Circuit opens after 3 failures for 20 seconds. Check logs:

grep "Circuit opened" logs/trendpulse.log

Trace Requests

curl -H "x-trace-id: my-debug-trace" \
  http://localhost:8100/v1/generate \
  -d '{"theme":"test","platform":"mobile"}'

Performance Issues

Slow responses
  • Check LLM latency with /ready ping test
  • Use low_cost mode for faster models
  • Increase timeout if network is slow
  • Check for provider rate limits
High memory usage
  • Check for memory leaks in long-running process
  • Monitor Python garbage collection
  • Check rate limiter cleanup (memory leak fix applied)
  • Restart container periodically
High CPU usage
  • Check for infinite loops in retries
  • Monitor concurrent requests
  • Check for blocking I/O
  • Use async properly
