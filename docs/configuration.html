Environment Variables

LLM Providers

Variable Required Default Description
OPENROUTER_API_KEY Yes* - OpenRouter API key
GEMINI_API_KEY Yes* - Google Gemini API key
OPENROUTER_BASE_URL No https://openrouter.ai/api/v1 OpenRouter endpoint
GEMINI_BASE_URL No https://generativelanguage.googleapis.com Gemini endpoint

* At least one provider required

Provider Settings

Variable Default Description
DEFAULT_PROVIDER openrouter Primary LLM provider
FALLBACK_PROVIDER gemini Fallback provider
DEFAULT_MODEL openrouter/auto Default model

LLM Resilience

Variable Default Description
LLM_REQUEST_TIMEOUT_SECONDS 30 Request timeout
LLM_MAX_RETRIES 1 Max retry attempts
LLM_RETRY_BACKOFF_SECONDS 0.25 Initial backoff (exponential)
LLM_CIRCUIT_BREAKER_FAIL_THRESHOLD 3 Failures before circuit opens
LLM_CIRCUIT_BREAKER_OPEN_SECONDS 20 Circuit open duration

Rate Limiting

Variable Default Description
RATE_LIMIT_REQUESTS 30 Requests per window
RATE_LIMIT_WINDOW_SECONDS 60 Window duration

Observability

Variable Default Description
OTEL_ENABLED false Enable OpenTelemetry
OTEL_ENDPOINT http://localhost:4317 OTel collector endpoint
LOG_LEVEL INFO Logging level

Database (optional)

Variable Default Description
DATABASE_URL - Async database URL
DATABASE_POOL_SIZE 5 Connection pool size
DATABASE_MAX_OVERFLOW 10 Max overflow connections

Configuration File

Create .env in project root:

# LLM Providers
OPENROUTER_API_KEY=sk-or-v1-...
GEMINI_API_KEY=your-gemini-key

# Provider Settings
DEFAULT_PROVIDER=openrouter
FALLBACK_PROVIDER=gemini
DEFAULT_MODEL=openrouter/auto

# Resilience
LLM_REQUEST_TIMEOUT_SECONDS=30
LLM_MAX_RETRIES=1
LLM_CIRCUIT_BREAKER_FAIL_THRESHOLD=3
LLM_CIRCUIT_BREAKER_OPEN_SECONDS=20

# Rate Limiting
RATE_LIMIT_REQUESTS=30
RATE_LIMIT_WINDOW_SECONDS=60

# Observability
OTEL_ENABLED=false
OTEL_ENDPOINT=http://localhost:4317
LOG_LEVEL=INFO

Programmatic Configuration

from trendpulse.config import settings

# Access settings
print(settings.default_provider)
print(settings.llm_max_retries)

# Override at runtime
settings.llm_max_retries = 3
