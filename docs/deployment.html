Docker Production

Build Optimized Image

docker build -t trendpulse:latest --target production .

Run with Production Settings

docker run -d \
  --name trendpulse \
  -p 8100:8100 \
  -e OPENROUTER_API_KEY=${OPENROUTER_API_KEY} \
  -e GEMINI_API_KEY=${GEMINI_API_KEY} \
  -e LOG_LEVEL=WARNING \
  -e LLM_REQUEST_TIMEOUT_SECONDS=60 \
  --restart unless-stopped \
  trendpulse:latest

Docker Compose Production

version: '3.8'
services:
  trendpulse:
    build: .
    ports:
      - "8100:8100"
    environment:
      - OPENROUTER_API_KEY=${OPENROUTER_API_KEY}
      - GEMINI_API_KEY=${GEMINI_API_KEY}
      - LOG_LEVEL=WARNING
    restart: unless-stopped
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8100/health"]
      interval: 30s
      timeout: 10s
      retries: 3

Kubernetes

Deploy

kubectl apply -f k8s/

Check Status

kubectl get pods -l app=trendpulse
kubectl logs -l app=trendpulse

Scale

kubectl scale deployment trendpulse --replicas=3

HPA (Auto-scaling)

kubectl apply -f k8s/hpa.yaml

Production Best Practices

Security: Never commit API keys. Use secrets management (AWS Secrets Manager, HashiCorp Vault, etc.)
  • Use secrets — Store API keys in secrets manager
  • Enable HTTPS — Use reverse proxy (nginx, traefik)
  • Set up monitoring — Prometheus + Grafana
  • Configure logging — Ship to centralized log system
  • Set resource limits — CPU/Memory limits in containers
  • Use health checks — /health and /ready endpoints

Reverse Proxy (nginx)

server {
    listen 80;
    server_name api.trendpulse.com;
    
    location / {
        proxy_pass http://localhost:8100;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
