Prometheus Metrics

Endpoint

GET /metrics

Available Metrics

Metric Type Description
trendpulse_requests_total Counter Total generate requests
trendpulse_requests_success_total Counter Successful requests
trendpulse_requests_error_total Counter Failed requests
trendpulse_llm_latency_ms_sum Counter LLM latency sum (ms)
trendpulse_llm_latency_ms_count Counter LLM latency observations
trendpulse_provider_{provider}_requests_total Counter Requests per provider
trendpulse_provider_{provider}_latency_ms_sum Counter Latency per provider
trendpulse_provider_{provider}_cost_usd_total Counter Estimated cost per provider
trendpulse_provider_{provider}_tokens_total Counter Tokens used per provider

Example Query

# Success rate
rate(trendpulse_requests_success_total[5m]) / rate(trendpulse_requests_total[5m]) * 100

# Average latency
rate(trendpulse_llm_latency_ms_sum[5m]) / rate(trendpulse_llm_latency_ms_count[5m])

# Requests per second
rate(trendpulse_requests_total[5m])

OpenTelemetry

Enable Tracing

OTEL_ENABLED=true
OTEL_ENDPOINT=http://localhost:4317

Trace Context

Pass x-trace-id header to track requests:

curl -H "x-trace-id: my-custom-trace-123" \
  http://localhost:8100/v1/generate \
  -d '{"theme":"ai","platform":"mobile"}'

Health Checks

/health — Liveness

curl http://localhost:8100/health
# {"status": "ok"}

/ready — Readiness

curl http://localhost:8100/ready
# {"status": "ready", "provider": "openrouter"}

# Or if not configured
# {"status": "not_ready", "reason": "no_providers_configured"}

Alerting Rules

High Error Rate

groups:
- name: trendpulse
  rules:
  - alert: HighErrorRate
    expr: rate(trendpulse_requests_error_total[5m]) > 0.1
    for: 5m
    labels:
      severity: critical
    annotations:
      summary: "High error rate on TrendPulse"

High Latency

  - alert: HighLatency
    expr: rate(trendpulse_llm_latency_ms_sum[5m]) / rate(trendpulse_llm_latency_ms_count[5m]) > 5000
    for: 5m
    labels:
      severity: warning
    annotations:
      summary: "High latency on TrendPulse"

Logging

Log Format

JSON format with trace_id:

{"timestamp": "2026-04-18T10:30:00Z", "level": "INFO", "logger": "trendpulse.gateway", "trace_id": "abc-123", "message": "Success provider=openrouter"}

Log Levels

Level When
DEBUG Detailed debug info
INFO Normal operation
WARNING Warnings (retries, circuit open)
ERROR Errors (provider failures)
