⚙️ Installation

Deploy TrendPulse your way

← Back to Docs ← Getting Started Configuration →

Requirements

  • Python 3.11+
  • API Key — OpenRouter or Gemini
  • 512MB RAM minimum

Quick Install

pip install trendpulse

Development Install

git clone https://github.com/trendpulse/trendpulse.git
cd trendpulse
pip install -e ".[dev]"

Docker

Build

docker build -t trendpulse:latest .

Run

docker run --rm -p 8100:8100 \
  -e OPENROUTER_API_KEY=sk-or-... \
  -e GEMINI_API_KEY=... \
  trendpulse:latest

Docker Compose

docker compose up --build

Kubernetes

kubectl apply -f k8s/

Helm (optional)

helm install trendpulse ./charts/trendpulse

Serverless

AWS Lambda

# Package with SAM or Serverless Framework
sam deploy --guided

Google Cloud Run

gcloud run deploy trendpulse \
  --source . \
  --region us-central1 \
  --allow-unauthenticated

Verify Installation

curl http://localhost:8100/health
# {"status": "ok"}
