# TrendPulse PRD Workspace

Этот каталог хранит продуктовые артефакты (BMAD/BMM-стиль) для TrendPulse.

## Содержимое

- `prd-v1.md` — основной PRD (цели, scope, user stories, KPI, NFR, риски).
- `mvp-scope-v1.md` — границы MVP и критерии “что входит / что не входит”.
- `assumptions-and-risks-v1.md` — допущения, риски, меры снижения.

## Правила

1. Любое изменение scope фиксировать в `mvp-scope-v1.md`.
2. Все KPI должны иметь owner, период и источник данных.
3. Спорные требования сначала переводить в гипотезы и эксперименты.
